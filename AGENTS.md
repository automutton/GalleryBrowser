# GalleryBrowser Collaboration

- `main` is the stable, verified development line.
- Experimental work must be done on a `feature/<short-name>` branch.
- Do not merge an experimental branch into `main` until the user explicitly confirms the feature has been tested.
- Build both the Svelte UI and the .NET solution after implementation when possible.
- Keep generated output, local databases, thumbnails, and IDE files out of commits according to `.gitignore`.
